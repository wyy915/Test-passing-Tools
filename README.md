# 本地题库刷题网页

一个可以在自己电脑上运行的刷题工具。上传题目文件后，系统会自动整理成题库，支持答题、判分、解析、错题复习和知识点背诵。

## 主要功能

- 支持上传 `PDF`、`Word（DOCX）`、`PPTX`、`TXT` 和 `Markdown` 文件。
- 支持分别上传题目文件和答案文件，并按题号匹配答案与解析。
- 也支持只上传一个文件，自动尝试识别题目、选项、答案和解析。
- 按题目文件名创建题库模块，同名模块再次导入时会自动合并。
- 支持单选题、多选题和判断题。
- 选择答案后可以立即判断对错并查看正确答案和解析。
- 多选题支持先选择多个选项，再点击“确认选择”提交。
- 每道题支持单独计时。
- 自动保存每道题的历史作答记录，包括上次答案、对错、作答次数和累计用时。
- 支持提取 Word、PDF、PPTX 中的题目配图，并显示在题干中。
- 支持“背知识点”模式：
  - 选择“记得了”进入下一个知识点。
  - 选择“忘记了”会让知识点之后再次出现。
- 支持手动勘误正确答案，勘误结果会保存到本地题库。
- 支持将题目加入错题本，并按分类整理。
- 错题本中的题目会一直保留，只有手动删除后才会移除。
- 支持删除单道题目和整个题库模块。
- 所有数据保存在本机，不需要联网使用，也不需要单独安装数据库服务。

## 环境要求

- Python 3.10 或更高版本
- Windows、macOS 和 Linux 均可使用

不需要安装 Node.js，也不需要执行 `npm install`。

## 从 GitHub 获取代码

```bash
git clone <你的 GitHub 仓库地址>
cd ni
```

如果仓库名称不是 `ni`，请把第二行的目录名替换成实际目录名。

## 启动方式

### macOS

双击项目中的 `start.command`。

如果第一次双击提示没有执行权限，可以在终端中运行：

```bash
chmod +x start.command
./start.command
```

也可以手动启动：

```bash
python3 start.py
```

### Windows

双击项目中的 `start.bat`。

也可以在 PowerShell 或命令提示符中运行：

```bat
py start.py
```

如果电脑没有 `py` 命令，可以尝试：

```bat
python start.py
```

### Linux

在终端中运行：

```bash
python3 start.py
```

### 第一次启动

首次启动时，程序会自动：

1. 创建本地 Python 虚拟环境 `.venv`。
2. 安装 `requirements.txt` 中的依赖。
3. 启动本地服务。
4. 尝试自动打开浏览器。

网页地址：

```text
http://127.0.0.1:8765/
```

如果浏览器没有自动打开，请手动复制这个地址访问。

## 使用方法

### 导入题目

1. 打开“题库总览”。
2. 点击“导入文件”。
3. 在“题目文件”中选择题目文档。
4. 如果答案单独存放，再在“答案文件”中选择答案文档。
5. 点击“开始导入”。

答案文件可以是 PDF、DOCX、PPTX、TXT 或 Markdown。建议答案文件名中包含“答案”“解析”“参考答案”或 `answer` 等关键词。

### 开始刷题

进入题库模块后，点击“开始刷题”：

- 单选题和判断题：选择选项后立即判题。
- 多选题：选择多个选项后点击“确认选择”。
- 判题后可以查看正确答案和解析。
- 题目右上角会显示当前题目的用时。
- 如果发现答案不正确，可以点击“勘误答案”重新选择正确答案并保存。

### 背知识点

只有知识点、没有题目的文件也可以导入。进入对应模块后点击“背知识点”：

- 记得知识点时点击“记得了”。
- 暂时不记得时点击“忘记了”，该知识点会在后面再次出现。

### 错题本

答错后可以手动加入错题本，并选择分类。错题本支持：

- 按分类筛选。
- 手动练习。
- 修改题目分类。
- 删除错题记录。
- 对题目进行答案勘误。

## 本地数据位置

题库使用项目目录中的本地文件保存数据：

```text
data/question_bank.json
```

题目原文件保存在：

```text
uploads/
```

题目中的图片保存在：

```text
uploads/images/
```

因此，备份或迁移题库时，请一起保留 `data/` 和 `uploads/` 文件夹。

## 发布到 GitHub 前的提醒

如果题库中包含个人资料、内部试题或其他不希望公开的内容，请在上传 GitHub 前检查并清理：

- `data/question_bank.json`
- `uploads/`
- `uploads/images/`

如果只想分享程序本身，可以保留空的 `data/` 和 `uploads/` 文件夹，不要上传个人题库和原始文件。

## 停止程序

在运行 `start.py` 的终端窗口中按：

```text
Ctrl+C
```

也可以直接关闭启动脚本打开的终端窗口。
